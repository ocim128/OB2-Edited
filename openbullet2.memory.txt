WPF desktop UI in OpenBullet2.Native built with MahApps.Metro and PackIcon libraries.
ModernMainWindow (MahApps.MetroWindow): 2-column layout (260 px sidebar + Frame content), dark title bar, centered startup, resizable.
Sidebar navigation buttons: Home, Jobs, Monitor, Proxies, Wordlists, Configs (submenu), Hits, Plugins, OBSettings, RLSettings, About.
Sidebar footer: Screenshot placeholder & Update Available button bound to UpdateAvailable flag.
Top bar shows pageTitle and quick-action icons (New/Open/Save Config).
mainFrame hosts pages; loadingIndicator (ModernProgressRing) overlays content when IsLoading.
Config submenu (Border) appears on navConfigs hover via TransformToAncestor and hides after 100 ms.
Pages are XAML UserControls under Views/Pages with matching ViewModels inheriting ViewModelBase.
Styles/ModernTheme.xaml defines dark palette (ThemeMain #3B82F6, BackgroundMain #0F172A) and Heading1-3 / Body / Caption text styles.
App.xaml merges MahApps Dark.Blue + ModernTheme and registers StyledButton family (Primary, Success, Warning, Danger).
ModernCard style: BackgroundCard (#1E293B), CornerRadius 12, Shadow 8 px, Padding 20.
CompactCardStyle (Corner 8, Padding 16) and StandardCardStyle (Corner 12, Padding 20) provide card variations.
Spacing helper styles: StandardSpacing 16, Compact 12, Tight 8 margins.
ModernButton template uses ClipBorder + drop shadow; ModernNavButton extends it, accent background on press.
ModernScrollBar (Thumb Corner 6) used in Configs, Jobs, etc.; search boxes use mah:TextBoxHelper.Watermark.
ListViewItem template sets BackgroundSecondary on hover/selected; VirtualizingStackPanel enabled.
Home page: hero welcome, live system info (uptime, memory, version) and collection stats cards.
Jobs page: header (search + New/Clear All), ItemsControl lists jobs; opens MultiRunJobViewer / ProxyCheckJobViewer.
MultiRunJobViewer: TabControl with Log & Bots tabs, custom dark ScrollBar, hitsContextMenu/botsContextMenu.
Monitor page currently placeholder cards under construction.
Configs page: toolbar New/Edit/Save/Delete/Export, search, Open Folder, Rescan; ListView supports drag-drop reorder.
Wordlists page: toolbar Add/Delete/Export/Search; ListView with checkbox column & context menu.
Proxies page: group toolbar (Add/Edit/Delete) + operations toolbar (Import/Export/Delete); ListView with copy context menu.
Hits page: Delete / Delete Duplicates / Purge toolbar; context menu Copy / Save / SendToRecheck.
RLSettings: stacked Borders (General, Proxy, Captcha) using NumericUpDown; Save button.
OBSettings: General, Proxy Check Targets, Custom Snippets, Remote Configuration cards; dynamic ItemsControls.
Debugger: input panel (TestData, Step-By-Step, UseProxy, PersistLog) + Start/Stop/Step buttons (Perfect* styles).
Debugger results: Log tab embeds WindowsFormsHost RichTextBox with line counter overlay & search bar.
PerfectStartButton / PerfectStopButton styles: gradient green/red, hover scale, play/stop icons.
ConfigStacker: three-column grid (block list, splitter, block info); toolbar square colored buttons; BoolToThickness border highlight.
ConfigLoliCode: AvalonEdit editor + optional Usings & Startup sections; syntax via LoliCode.xshd.
ConfigCSharpCode: AvalonEdit C# editor with syntax highlighting.
SettingViewer controls map BlockSetting types to UI (String/Bool/Int/Float/Enum/List/Dictionary editors).
ListOfStringsSettingViewer & DictionaryOfStringsSettingViewer manage dynamic collections with add/remove rows.
KeychainViewer / KeyViewer show captured credential key-values with copy actions.
AutoBlockSettingsViewer builds list UI for AutoBlock entries with Add/Remove.
ColoredLog control color-codes RichTextBox log lines.
Converters: BooleanConverter.cs provides BoolToVisibility & BoolToThickness; BoolToVis used across pages.
Global icon styles inherit ForegroundMain; SuccessButton (#065F46) & DangerButton (#991B1B) brushes for Styled buttons.
Card overlays often use translucent #C0353535 background for depth on dark theme.
GridSplitters allow sidebar resizing (e.g., ConfigStacker vertical splitter).
Margins: root page Grids use 24,20,24,24 (standard) or 16 (settings) for consistent spacing.
ModernHomeViewModel exposes ApplicationUptime, MemoryUsage, ApplicationVersion & collection counts to Home page.
DropShadowEffect resource defined in App.xaml reused by cards & buttons.
ModernScrollBarThumb opacity changes on hover/drag; RepeatButtons transparent (no arrows).
Watermarked search placeholders hide via BoolToVis when TextBox not empty.
Styled buttons animate scale (1.02 hover, 0.98 pressed) with drop shadow.
AvalonEdit highlighting files stored in OpenBullet2.Native/Highlighting/*.xshd.
Context menus (proxies, hits, wordlists) defined in Page.Resources and attached to ListViews. 
CleanComboBox style (Debugger) provides dark rounded dropdown, custom ToggleButton arrow, hover/focus border accent.
SquareCheckBox style (Debugger) draws 16x16 dark square box with green tick path and hover border.
MatchingTextBox style (Debugger) gives dark background, rounded border, accent focus border brush.
PerfectStartButton and PerfectStopButton gradients defined globally in App.xaml and duplicated in Debugger for isolation.
MahApps NumericUpDown controls re-templated: dark BackgroundInput, Consolas font, up/down buttons hidden.
Grid header templates in ListViews override default to left-align text and change header click sorting tags.
ContextMenu dark style: background #1A1A1A, padding 4, drop shadow resource, white foreground.
Agents across pages declare BoolToVis converter in resources; some also declare BoolToThickness via BoolToThicknessConverter.
Coded styles for icon packs in App.xaml set ForegroundMain (#F8FAFC) ensuring icons adapt to theme.
Scrollbar RepeatButtons are invisible (ModernScrollBarPageButton) removing arrow buttons for minimal look. 
TimeSpanPicker control offers hours/minutes/seconds NumericUpDown inputs for selecting durations in block settings.
MultipleSelector control displays token list with checkboxes allowing multi-select of strings within SettingViewer UIs.
ImagePicker control lets users browse and preview PNG/GIF images for img-type settings in blocks.
HTMLViewer wraps WebBrowser control to render raw HTML content (e.g., config documentation) inside the app.
MarkdownViewer converts markdown to FlowDocument via Markdig and shows it in a ScrollViewer for config readme.
HttpRequestBlockSettingsViewer and KeycheckBlockSettingsViewer present detailed grids for HTTP request & keycheck block parameters.
AutoBlockSettingsViewer lists auto-block rules with columns (Key, Operator, Value) and Add/Remove row buttons.
EnumSettingViewer binds ComboBox to enum values of Setting object and updates selection on change.
ColoredLog uses regex to color spans (green success, red error, yellow warning) inside RichTextBox.
MetroWindow GlowBrush="Black" and BorderThickness="0" give frameless window with subtle outer glow. 
ProxyCheckJobViewer page shows job parameters (Url, SuccessKey, Timeout, Bots) and provides Start/Resume/Pause/SkipWait/Stop/Abort buttons using Styled*Button styles.
ProxyCheckJobViewer binds Progress value to ProgressBar and text overlay Job.ProgressString centered.
Proxy stats panel displays Total, Tested, Working (green), Not working (red) labels; Other panel shows CPM, Elapsed, Remaining.
Job log at bottom uses ColoredLog control for proxy-check job output.
ReadableTabButton style (App.xaml & Debugger) defines pill-shaped button with custom background, white text, used for Debugger Tab headers and search actions.
StyledWarningButton based on StyledButton uses WarningButton brush (#92400E) for caution actions like Pause.
MatchingTextBox style adds accent border on focus and is reused for TestProxy input in ProxyCheckJobViewer.
Progress bars use default style with dark track; overlay TextBlock uses BackgroundSecondary as foreground to mask text until bar fills.
Jobs List row shows StatusColor small circle indicator and colored border on hover; progress cell shows percentage text.
Jobs Config Name column uses Foreground=ThemeMain when selected to highlight currently running job row. 
MultiRunJobViewer includes tab buttons (Valid, Custom, ToCheck) as small Buttons updating ItemsSource filter.
HitsCollection ListView inside MultiRunJobViewer uses custom header styles and ModernScrollBar.
MultiRunJobViewer footer Border displays CPM, Elapsed, Remaining plus hit counters (Hits, Custom, ToCheck, Retried, Banned, Fail, Error).
Progress stats text uses color coding: Hits ForegroundGood, Custom ForegroundCustom, ToCheck ForegroundToCheck, etc.
ProxyCheckJobViewer stats footer shows CPM, ElapsedString, RemainingString and color-coded progress values.
ProxyCheckJobViewer uses Job.ElapsedString and RemainingString bindings to show times.
Start/Resume/Pause buttons visibility bound to booleans (CanStart, CanResume, CanPause) via BoolToVis converter.
ChangeBots icon (PackIconRemixIcon) next to Bots count opens dialog to edit bot count.
ListViewItem styles for ProxyCheckJobViewer's resultsListView set Transparent background, darker on hover/selected.
Grid progress bar overlay uses separate Border with TextBlock to display Job.ProgressString above ProgressBar.
